# Redistribution review

This project does not assign a license to the user's new application code. Choose an application license before public distribution.

Verified upstream licenses:
- deface 1.5.0: MIT, https://github.com/ORB-HD/deface/blob/master/LICENSE
- CenterFace upstream project/model: MIT, Copyright 2019 StarClouds, https://github.com/Star-Clouds/CenterFace/blob/master/LICENSE
  The bundled deface centerface.onnx model originates there. Upstream MIT does not independently establish training dataset rights; review intended use and model provenance before a public release.
- ONNX Runtime 1.24.3 (1.20.1 on Intel macOS): MIT, https://github.com/microsoft/onnxruntime/blob/main/LICENSE
- ONNX: Apache-2.0, https://github.com/onnx/onnx/blob/main/LICENSE
- OpenCV >=4.5: Apache-2.0; opencv-python wheel packaging is MIT. Wheels have additional third-party notices and bundled libraries; included package LICENSE files must accompany redistribution.
- Python: PSF license plus historical licenses, https://docs.python.org/3/license.html
- PyInstaller: GPL-2.0 with bootloader exception; freezing does not impose GPL on the application. https://pyinstaller.org/en/stable/license.html
- React, shadcn/ui, Radix, Tailwind, Vite, lucide-react, TypeScript: MIT or ISC (lucide); exact installed notices are collected by build_sidecar.py.
- Tauri and official plugins: MIT OR Apache-2.0. Rust transitive license inventory is generated by cargo-about in CI.

FFmpeg is LGPL by default. This application needs libx264, so its controlled tool build uses GPL FFmpeg and GPL x264. --enable-nonfree is rejected. The GPL tools execute as separate processes; the exact application/distribution license compatibility must be reviewed. Include the corresponding complete FFmpeg/x264 source archives, build script, configuration, and GPL texts with every binary distribution. CI bundles them inside each installer under licenses/sources, and retains target-specific source/notice archives as CI artifacts. Do not substitute third-party binaries without checking their configuration and providing their corresponding sources. H.264/AAC patent obligations vary by jurisdiction and are not resolved by software license notices.

Release blockers: select the application license, review model/training-data provenance, complete review of native libraries pulled in by Python wheels (especially OpenCV's embedded FFmpeg and macOS linked libraries), review bundled WebView2/GStreamer/media-framework redistribution terms and notices, and validate corresponding-source/relink obligations for the actual release artifacts. Development installers are not a licensing clearance. Signing credentials are configured exclusively through GitHub Actions Secrets; absent credentials produce explicitly unsigned builds.
